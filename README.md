# ДРАГМЕТ

Идл-игра про бомжа-аффинажника: копаешься в мусоре → собираешь электронику → растворяешь в кислоте → выпариваешь в печи → продаёшь золото скупщику → прокачиваешься → престиж → кузница с амулетами.

## Текущий статус

- **Стадия:** рабочий HTML-прототип, идёт визуальный редизайн.
- **Версия:** v0.9 (код сейва `ver: 24`).
- **Формат:** один файл `index.html` + две картинки в той же папке: `kuznec.png` (открытый кузнец), `kuznec-locked.png` (закрытый, тёмный размытый силуэт).
- **Где живёт:** GitHub Pages (`txnto-exe.github.io/dragmet`), открывается в Safari на iPhone, добавлен на домашний экран как PWA.
- **Тестируют:** друзья (обычные игроки, не программисты).

## ГЛАВНЫЕ ПРАВИЛА РАБОТЫ С АВТОРОМ

**Эти правила железные. Нарушались уже много раз — не повторять.**

1. **Никакого кода без явной команды.** Пока автор не сказал «пиши» или «делай» — код не пишется, не предлагается, не показывается. Только обсуждение, анализ, вопросы.
2. **Только полные готовые файлы.** Никогда не давать куски кода. Никогда не говорить «найди там, замени тут, посмотри здесь». Только целиком `index.html`, который автор копирует и заменяет.
3. **Автор не программист.** Объяснять по-простому, без терминов. Если нужен термин — сразу расшифровывать.
4. **Без воды.** Отвечать коротко и по делу.
5. **Сначала слушать, потом предлагать.** Автор сам говорит что нужно и в каком порядке. Не лезть с непрошеными советами.
6. **Перед задачей — уточнять и проговаривать.** Если задача размытая — задать уточняющие вопросы, резюмировать «что именно делаем», дождаться «делай».
7. **Не делать всё сразу.** Большие задачи разбивать на этапы и создавать план. Начинать только после подтверждения.
8. **Если автор путается — попросить скрин.** Один скрин снимает десять уточняющих вопросов. Не гадать.
9. **Если фикс не работает — не просить автора «заменить две функции».** Автор не программист. Только целый файл.
10. **Не писать код кусками и не останавливаться на середине.** Если начал писать файл — писать от первой строки до последней, целиком.

## Технический стек

- **Чистый HTML + CSS + vanilla JS.** Никаких библиотек, фреймворков, npm, сборщиков.
- **Причина:** простота, скорость правок, открывается где угодно, легко превращается в нативное приложение через WebView.
- **Не менять этот принцип** без явной просьбы.

## Структура файла

Один файл `index.html` содержит:
- CSS (в `<style>`),
- HTML-разметку (экраны меню, игры),
- весь JS в одном IIFE (в `<script>`).

Плюс картинки в **той же папке**, что `index.html`:
- `kuznec.png` — открытый кузнец.
- `kuznec-locked.png` — закрытый кузнец (тёмный размытый силуэт).

## Экраны игры

- **Меню** (`menuScreen`): Продолжить / Новая игра.
- **Игра** (`gameScreen`): 5 вкладок.
  - **Кузнец** (`forge`) — открывается после первого престижа. До престижа на иконке — только 🔒 без подписи.
  - **Печь** (`fire`) — выпаривание раствора в слитки, скупщик, продажа.
  - **Копать** (`dig`) — основная вкладка, точки сбора, инвентарь. **Без вертикального скролла.**
  - **Кислота** (`acid`) — растворение лома.
  - **Прокачка** (`upg`) — все апгрейды + престиж. Две вкладки: Обычная / Престиж.
- **Оверлей оффлайн-дохода.**
- **Оверлей стоп-игры «Контроль цены».**
- **Две мини-игры:** «Растворение» (кислота) и «Выплавка» (печь).
- **DEV-консоль** — по долгому зажатию (3 сек) на кнопку шестерёнки в шапке.

## Игровая петля

1. **Копать** — на локациях тратится «запас» точки, находит мусор.
2. **Кислота** — растворяет лом, часть золота теряется. Перед запуском — мини-игра.
3. **Печь** — выпаривает раствор, получаются слитки. Перед запуском — мини-игра.
4. **Скупщик** — продажа слитков через стоп-игру.
5. **Прокачка** — апгрейды + престиж.
6. **Кузница** (после первого престижа) — крафт амулетов из мусора.

## Сохранения

- **Два независимых слота:** `dragmet_save_a_v2` и `dragmet_save_b_v2`.
- Пишем по очереди в тот слот, у которого **меньше** timestamp.
- При загрузке берём тот, что свежее.
- **Старые ключи** удаляются при запуске.
- **Текущий `ver`: 24.** При загрузке старого сейва без `forgeCrafts` — конвертируется из старого `forgeCraft`. Поле `priceControl` больше не сохраняется.

## Игровые механики (важное)

### Автокопатели

- Покупаются за кэш, по одному на локацию: 800 / 2 500 / 6 000 / 15 000 / 35 000 / 80 000 / 180 000 / 260 000 / 400 000 ₽.
- Работают без траты стамины точек (так задумано, не баг).
- Не сбрасываются при престиже.
- Прокачки общие: «Скорость работяг» (+10% за уровень) и «Снижение штрафа» (−5% за уровень, максимум 10).
- Замедлены в 3 раза (`AUTO_SLOW_FACTOR = 3`).

### Оффлайн-доход

- Считается от купленных автокопателей.
- **Порог срабатывания — 5 минут.**
- `lastSeenTs` обновляется всегда.
- Лимит часов по умолчанию 1 час, до 10.
- Коэффициент оффлайна — база 0%, +5% за уровень, до 75%.
- **Модалка:** время, крупная сумма, случайная фраза (8 вариантов), кнопка «Забрать».

### Кузница

- **Открывается после первого престижа.**
- **До престижа:** `kuznec-locked.png` нормальной яркости, сверху плашка с 🔒 и надписью «ЗАКРЫТО». Анимации выключены. Заголовок «Кузница» и аккордеон в Прокачке спрятаны. В таббаре — только 🔒. Подпись таба — пустая.
- **После престижа:** `kuznec.png`, все анимации включены, всё показывается.

**Анимации кузнеца (только когда открыта):**
- Дыхание картинки (4.2 сек цикл).
- Дым от сигареты: 7 частиц, точка `50% / 24%`.
- Свечение лампы: `91% / 58%`, цикл 2.4 сек.
- Тёплый пульс снизу.
- Светлячки: 5 точек вокруг лампы (`85–92%` / `46–52%`).
- Замок (когда закрыта) — плавно парит вверх-вниз.

### Амулеты (10 штук)

- Один слот одновременно.
- Эффекты: Ночная смена, Второй шанс, Золотая жила, Чистюля, Печной демон, Расширитель, Щедрый скупщик, Мусорщик, Легендарный охотник, Терпеливый.
- Рецепты — чипами `🔌 Микросхемы 3/5`, красные если не хватает.
- **Удаление:** свайп влево → красная корзина → тап → растворяется, вернёт 40%. Без `confirm`.
- **При престиже:** амулеты остаются, срок в престижах −1.

### Крафт амулетов

- **Один горн** по умолчанию.
- **«Два горна»** — 25 000 ₽, в Прокачке → Кузница. Позволяет запустить два параллельно.
- **Нельзя запустить один и тот же амулет дважды** — проверяется `forgeCrafts`.
- Пока слоты заняты — кнопки «Занят».

### Прокачка кузницы

- **Быстрее куём** — −10% времени за уровень, макс 7.
- **Дешевле рецепты** — −5% ресурсов, макс 10.
- **Дольше живут** — +1 престиж / +25% времени за уровень, макс 5.
- **Два горна** — покупка один раз, 25 000 ₽.

### «Контроль цены» (стоп-игра)

- **Доступна с самого начала.**
- Кнопка «Продать» → бегунок, зелёная зона, тап → стоп.
- **До тапа** — диапазон цен (`800 – 4000 ₽/г`).
- **После тапа** — выпавшее число.
- Попал в зону → 4000 ₽/г, промазал → от 3900 до 800.
- **«Широкая зона»** — +1% ширины за уровень, макс 5. База 5 000 ₽ × 1.7^lv.

### Престиж

- **Порог:** `100 000 × 1.5^уровень`.
  - 0→1: 100 000 ₽
  - 1→2: 150 000 ₽
  - 2→3: 225 000 ₽
  - 5→6: ~1,14 млн ₽
  - 10→11: ~8,6 млн ₽
- **Награда:** `10 × 2.5^(уровень-1)`.
- **Максимум 20 уровней** (`MAX_PRESTIGE_LEVEL = 20`).
- **Что сбрасывается:** деньги, слитки, лом, раствор, обычные прокачки, локации, склад.
- **Что остаётся:** автокопатели, амулеты, очки престижа, апгрейды престижа.

### Конечность прокачек

**У всех прокачек есть финальный уровень.** Максимумы (`MAX_*`):

- Кислота 15, Печь 15, Склад 25, Турбо-палец 1 (покупка).
- Копать быстрее 10, Кислота быстрее 20, Печь быстрее 20.
- Второй бак 1 (покупка), Вторая печь 1 (покупка).
- Хороший глаз 20, Чуйка 15.
- Репутация 10, Широкая зона 5.
- Оффлайн-коэффициент 15, Оффлайн-лимит 9.
- Скорость работяг 10, Снижение штрафа 10.
- Кузница: Быстрее куём 7, Дешевле рецепты 10, Дольше живут 5, Два горна 1.
- Престиж: Усиление бонуса 20, Стартовый капитал 20, Скидка на локации 15, Кислота II 10, Печь II 10, Склад II 25.
- Восстановление точек 10.

### Мини-игра «Растворение» (кислота)

- Обязательна перед запуском любого бака кислоты. Со старта.
- Три колбы: 💧 Вода / 🧪 Кислота / ⚗️ Щёлочь.
- Скорость у всех разная (вода 40, кислота 55, щёлочь 70 %/сек).
- Зона-мера на каждой колбе — своя, случайная (позиция 12–72%, ширина 16–22%).
- Зажал кнопку — колба едет вверх. Дошла до верха — едет вниз. Отпустил — стоп.
- Попал в зону — колба зелёная, зафиксирована.
- Промахнулся — красная вспышка, всё закрылось, заново.
- Все три попал — процесс запускается.
- **Grace 3 сек:** после победы 3 секунды можно запустить второй бак без мини-игры. Визуального таймера нет.

### Мини-игра «Выплавка» (печь)

- Обязательна перед запуском печи. Со старта.
- Горизонтальная полоса, оранжевая зона ходит туда-сюда.
- Скорость зоны 35–55 %/сек, стартовая позиция случайна.
- Кнопки «−» (голубая) и «+» (оранжевая). Зажал — бегунок едет. Отпустил — стоп. Тап — толчок.
- Скорость бегунка всегда одна.
- Индикатор «Готовность»: в зоне растёт (за 3 сек до 100%), вне зоны быстро падает (за 1 сек до 0%).
- Скрытый счётчик провала: суммарно 5 сек вне зоны → провал.
- Победа — процесс запускается.
- **Grace 3 сек:** после победы 3 секунды можно запустить вторую печь без мини-игры.

### Звук

- Единый уровень `SND_VOL × VOL_MUL = 0.07 × 14`.
- Тон кислоты 600 → 1800 Гц.
- Печь — потрескивание 800–1800 Гц.
- **`tone()` и `slide()`** имеют мёртвый параметр `vol` — оставлен, потому что удаление требует переписать ~30 вызовов. Не баг.

### Тост о находке

- **Внутри вкладки «Копать»** — плавающий, встаёт на строку «N/M» между стрелками локаций.
- **В других вкладках** — по центру панели.
- Цвет по тиру предмета.

### Управление касаниями

- **«Копать» и «Продать»** — моментально (30 мс). Держишь → турбо-палец. Сдвинул >12px → не копает и не скроллит.
- **Всё остальное** — срабатывает при отпускании, если палец не сдвинулся.
- **Тап «Порыться» в кулдауне** — лёгкий звук + вибро.

### Скроллбары

Скрыты везде.

### Вкладка «Копать» — особенности

- **Без вертикального скролла.** `100dvh`.
- **Точки сбора:** по 3 на страницу, страниц 3 (9 локаций). Стрелки ← →, плавный слайд 0.36 сек.
- **Инвентарь:** всегда открыт, 16 предметов, **4×4**, ровный квадрат.

### Шапка игры

Три блока:
1. **Деньги + слитки.** До престижа — деньги и граммы в одну строку. После престижа — деньги сверху, граммы снизу.
2. **Престиж** (появляется с первого престижа). В две строки: ★ уровень / очки.
3. **Амулет.** Иконка + название. Без амулета — «Нет амулета». Длинное название обрезается.

Каждый блок — в своей плашке, у каждой свой цвет.
Шестерёнка справа. **Короткий тап — настройки. Зажатие 3 сек — DEV-консоль.**

Логотип ДРАГМЕТ из шапки **убран**.

### Таббар

**Плавающий.** Отступ 12px от краёв и низа (+ безопасная зона iPhone). Скругление 28px со всех сторон. Стекло (blur 24px).

Центральная кнопка возвышается на −26px, не режется таббаром.

### Визуальный стиль

- Тёмный, землистый, ржаво-зелёный.
- **Обводок нет.** Разделение через оттенки фона и мягкие тени.
- Радиусы: 22px панели, 18px карточки, 14px кнопки.
- Много воздуха: паддинги 18px, gap 8–10px.
- Свечения: активная локация, кнопка «Порыться», найденный предмет, деньги, очки престижа.
- Анимации: появление панелей снизу, пульс активной локации, анимация таб-иконок, pop модалок, парение замка.
- Типографика: деньги 20px жирные, граммы 17px, заголовки панелей 15px, названия прокачек 14.5px, описания 11.5px, цифры в инвентаре 15px, слитки 34px.

## Легенда терминов

- **Сейв** — сохранение.
- **Слот** — один из двух файлов сохранения.
- **Престиж** — сброс прогресса за постоянные бонусы.
- **Автокопатель** — работяга на локацию.
- **Стамина** — запас точки.
- **dt** — время между кадрами.
- **PWA** — веб-приложение на домашнем экране.
- **WebView** — встроенный браузер внутри приложения.
- **Стоп-игра** — мини-игра с бегунком.
- **Bloom** — свечение от амулета.
- **Дев-консоль** — скрытая панель для тестов.
- **dvh** — динамический viewport height.
- **DOM** — «дерево» элементов страницы (что видит игрок).
- **innerHTML** — способ перерисовать блок с нуля.
- **Bento** — разбивка одной большой панели на несколько отдельных блоков.
- **Grace** — короткий период после победы в мини-игре, когда повторная не требуется.
- **`MAX_*`** — переменная в коде, которая хранит максимальный уровень прокачки.
