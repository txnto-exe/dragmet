# ДРАГМЕТ

Идл-игра про бомжа-аффинажника: копаешься в мусоре → растворяешь лом в кислоте → выпариваешь в печи → продаёшь слитки скупщику → прокачиваешься → престиж → кузница с амулетами → авто-фабрика.

- **Версия:** v0.17 (формат сейва `3`).
- **Где живёт:** GitHub Pages (`txnto-exe.github.io/dragmet`), открывается в Safari на iPhone и добавлен на домашний экран как приложение.
- **Стек:** чистые HTML + CSS + JavaScript. Без библиотек, сборщиков и npm. Игра открывается и с сайта, и двойным кликом по `index.html`.

## Как устроены файлы

```
index.html          разметка экранов (что где лежит на экране)
css/style.css       внешний вид
kuznec.png          кузнец (открыт)
kuznec-locked.png   кузнец (закрыт, до первого престижа)
js/
  util.js           мелкие помощники (найти элемент, записать текст, формат чисел)
  data.js           ДАННЫЕ: предметы, локации, амулеты, числа баланса, тексты
  art.js            ПИКСЕЛЬ-АРТ: палитра и все спрайты (предметы, иконки, герой, скупщик)
  formulas.js       ФОРМУЛЫ: скорости, шансы, цены престижа, эффективность
  state.js          как устроено состояние игры (что сбрасывается при престиже, что нет)
  upgrades.js       ТАБЛИЦА ВСЕХ ПРОКАЧЕК
  save.js           сохранение, загрузка, перевод старых сейвов
  audio.js          8-битные звуки, фоновая музыка, вибрация
  game.js           игровая логика: копка, кислота, печь, продажа, престиж, кузница, фабрика, оффлайн
  minigames.js      мини-игры «Растворение», «Выплавка», стоп-игра «Контроль цены»
  scene.js          живые сцены: двор с героем, кислотная, печь, ларёк, меню; эффекты
  story.js          история и персонажи: долг Хозяину, бригада, портреты, диалоги, заказы Зины, Шнырь, участковый
  ui.js             экран: построение и обновление всего, что видно
  input.js          касания: что делает каждая кнопка
  dev.js            DEV-консоль (убрать перед релизом)
  main.js           запуск и главный цикл
_original/          копия версии от DeepSeek (на всякий случай, можно удалить)
```

### Где что менять

| Хочу… | Файл |
|---|---|
| Поменять баланс: цену, шанс, скорость | `js/data.js` (раздел `BAL`), `js/formulas.js`, цены прокачек — `js/upgrades.js` |
| Добавить предмет или локацию | `js/data.js` |
| Добавить амулет | `js/data.js` (`AMULETS`) + эффект там, где он работает (обычно `formulas.js` или `game.js`) |
| Добавить прокачку | одна строка в `js/upgrades.js` + формула, которая использует `lv('ключ')` |
| Поменять тексты | `js/data.js` (`TEXT`) и описания в `js/upgrades.js` |
| Поменять вид | `css/style.css` |
| Перерисовать предмет или иконку | `js/art.js` (спрайт — строки букв, буква = цвет из `PAL`) |
| Поменять сцену, фон точки сбора | `js/scene.js` (`LOC_LOOK` и функции `bg…`) |
| Реплики, персонажи, когда кто приходит, бонусы | `js/story.js` (`CREW`, `INTRO`, `CALLS`) |
| Портрет персонажа | `js/story.js` (`FACES`) |
| Поменять звук или музыку | `js/audio.js` (`MUSIC` — мелодия) |

### Главные правила кода

1. **Каждое число и формула записаны один раз.** Описание прокачки «было → станет» считается по той же формуле, что и игра, поэтому текст не может разойтись с механикой.
2. **Состояние делится на части:** `G.run` сбрасывается при престиже, `G.meta` остаётся навсегда. Чтобы новое поле переживало престиж, его достаточно положить в `G.meta`.
3. **Логика отдельно от экрана.** `game.js` меняет только состояние, а `ui.js` только показывает его.
4. **Ошибки не прячутся.** Если что-то сломалось, вверху экрана появится красная плашка с текстом ошибки. Сделай скрин — по нему сразу видно, что чинить.

## Сохранения

> ⚠️ На iPhone у иконки на домашнем экране своё хранилище. **Удалишь иконку — сотрёшь сейв.** Перед удалением сделай резервную копию в настройках.

- Два слота `dragmet_save_a_v3` / `dragmet_save_b_v3`, пишутся по очереди. При загрузке берётся более свежий.
- Автосохранение раз в 2 секунды, после важных действий и при сворачивании игры.
- **Старые сейвы** (версия DeepSeek, ключи `*_v2`) при первом «Продолжить» автоматически переводятся в новый формат. Сами старые ключи не удаляются: если откатиться на старую версию, прогресс на ней останется. Удаляются они только при «Новая игра» или «Сбросить».
- При загрузке сейв проверяется: кривые значения заменяются стартовыми, уровни обрезаются по максимуму.

## DEV-консоль

Зажать шестерёнку на 3 секунды. Внутри: деньги, слитки, очки, предметы.
**Перед релизом:** удалить файл `js/dev.js` и строку `<script src="js/dev.js">` в `index.html`. Больше ничего трогать не нужно.

## История

### v0.17 — история и бригада (ноябрь 2026)

- Завязка: Палыч должен Хозяину, тот звонит по таксофону. Престиж теперь — «взнос Хозяину», всего 20. После каждого взноса — звонок, на 20-м — финал.
- Сначала Палыч один у бочки. По ходу игры прибиваются: кот Помойка, Колян, Зина, Шнырь, Михалыч, Валёк, Профессор. У каждого сценка-знакомство с портретом и свой бонус.
- Окно «Лагерь»: живая сцена у бочки и карточки бригады (кто ещё не пришёл — силуэт и подсказка, как встретить). Бригада стоит у бочки и в главном меню.
- Заказы Зины: принеси, что просит, — получи деньги.
- Шнырь ворует на точках — тапни по нему, чтобы прогнать. После трёх раз просится в бригаду.
- Участковый: «Шухер!» — тапай по сцене, чтобы спрятать мешок, иначе заберёт часть лома.
- Знакомство с Жорой при первой продаже. У каждой точки свой работяга.
- На старых сейвах — короткая версия завязки; бригада, которой «положено» быть, приходит сразу.

### v0.16 — картинки везде (ноябрь 2026)

- Прокачки — карточки с картинкой и полоской уровня.
- Мини-игры нарисованы: колбы с жидкостью и струёй, печь со шкалой жара и тиглем, торг со скупщиком (он вслух называет цену).
- Катсцена престижа: монетный дождь, вспышка, рассвет, герой в новой одёжке.
- Покупки видны на сценах: ванны (ржавая → пластик → сталь, ур. 5 и 10), печи (бочка → кирпич → заводская), мешки растут со складом.
- Подсказки новичку по шагам (на старых сейвах не показываются).

### v0.12–v0.15 — пиксельный вид (ноябрь 2026)

- Весь интерфейс в пиксельном стиле: шрифт Galmuri11, рамки ступеньками, объёмные кнопки, кирпичный фон, цветные шапки разделов.
- Все эмодзи заменены нарисованными спрайтами.
- Живые сцены: на «Копать» герой роется в мусоре, у каждой из 9 точек свой фон; кислотная с ваннами, печь-буржуйка, ларёк скупщика, ночное главное меню с костром.
- Время суток и погода по часам телефона, кот, реплики героя и скупщика.
- Находки летят в мешок (редкие — со вспышкой), монеты при продаже летят в кошелёк.
- Точки сбора листаются стрелками на сцене, тап по сцене — порыться.
- 8-битные звуки и фоновая музыка (выключается в настройках).
- Альбом находок: что уже находил, не сбрасывается при престиже.

### v0.11 — стабильность (ноябрь 2026)

- Игра «идёт», пока она свёрнута или закрыта. Меньше 5 минут — всё работает как обычно (процессы, работяги, фабрика). Дольше — начисляется оффлайн-доход, начатые кислота и печь заканчиваются, точки восстанавливаются. Раньше при возврате из свёрнутого состояния ничего не начислялось.
- Резервная копия сейва в настройках: «Копировать» — сейв одной строкой (сохранить в заметки), «Вставить» — восстановить. Нужна, потому что на iPhone удаление иконки стирает сейв.
- «Дольше живут» теперь правда даёт +1 престиж срока амулетам «на престижи».
- Аварийная диагностика: если игра не запустилась, вместо белого экрана — текст с причиной.
- К файлам добавлена версия (`?v=0.11`), чтобы телефон не держал старые копии из кэша. **При каждом обновлении менять её в `index.html`.**
- Если сейв не записывается (память переполнена), игра об этом скажет.

### v0.10 — уборка после DeepSeek (ноябрь 2026)

Игра переписана с нуля по устройству, но **механика и баланс те же** (цифры версии 36).

Исправлено попутно:
- Переключатели «Звук» и «Вибрация» в настройках не сохраняли выбор — теперь работают.
- Очень быстрый тап по «Порыться» / «Продать» (меньше 0,03 сек) терялся — теперь срабатывает.
- Бейдж на «Прокачке» до первого престижа считал скрытые прокачки кузницы.
- Описание «Кислота быстрее» / «Печь быстрее» с амулетом «Печной демон» показывало «станет» без учёта амулета.
- Кнопка амулета «Одеть» → «Надеть».
- Сейв больше не перечитывает оба слота с диска при каждой записи.
- Престиж больше не держится на ручном списке «что не сбрасывать».
- Положение аккордеонов в «Прокачке» больше не сбрасывается при престиже.
