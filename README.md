# ДРАГМЕТ

Идл-игра про бомжа-аффинажника: копаешься в мусоре → собираешь электронику → растворяешь в кислоте → выпариваешь в печи → продаёшь золото скупщику → прокачиваешься → престиж → кузница с амулетами → автоматизация.

## Текущий статус

- **Стадия:** рабочий HTML-прототип. Автоматизация, техдолг и баланс темпа закрыты. Дальше — тест темпа, потом контент за престиж.
- **Версия:** v0.9 (код сейва `ver: 37`).
- **Формат:** один файл `index.html` + две картинки в той же папке: `kuznec.png` (открытый кузнец), `kuznec-locked.png` (закрытый, тёмный размытый силуэт).
- **Где живёт:** GitHub Pages (`txnto-exe.github.io/dragmet`), открывается в Safari на iPhone, добавлен на домашний экран как PWA.
- **Тестируют:** друзья (обычные игроки, не программисты).

## ГЛАВНЫЕ ПРАВИЛА РАБОТЫ С АВТОРОМ

**Эти правила железные. Нарушались уже много раз — не повторять.**

1. **Никакого кода без явной команды.** Пока автор не сказал «пиши» или «делай» — код не пишется, не предлагается, не показывается. Только обсуждение, анализ, вопросы.
2. **Только полные готовые файлы.** Никогда не давать куски кода. Никогда не говорить «найди там, замени тут». Только целиком `index.html`, который автор копирует и заменяет.
3. **Автор не программист.** Объяснять по-простому, без терминов. Если нужен термин — сразу расшифровывать.
4. **Без воды.** Отвечать коротко и по делу.
5. **Сначала слушать, потом предлагать.** Автор сам говорит что нужно и в каком порядке. Не лезть с непрошеными советами.
6. **Перед задачей — уточнять и проговаривать.** Если задача размытая — задать уточняющие вопросы, резюмировать «что именно делаем», дождаться «делай».
7. **Не делать всё сразу.** Большие задачи разбивать на этапы и создавать план. Начинать только после подтверждения.
8. **Если автор путается — попросить скрин.** Один скрин снимает десять уточняющих вопросов. Не гадать.
9. **Если фикс не работает — не просить автора «заменить две функции».** Только целый файл.
10. **Не писать код кусками и не останавливаться на середине.** Если начал писать файл — писать от первой строки до последней, целиком.
11. **Не додумывать.** Если не понял — переспросить. Не гадать.

## Технический стек

- **Чистый HTML + CSS + vanilla JS.** Никаких библиотек, фреймворков, npm, сборщиков.
- **Причина:** простота, скорость правок, открывается где угодно, легко превращается в нативное приложение через WebView.
- **Не менять этот принцип** без явной просьбы.

## Структура файла

Один файл `index.html` содержит:
- CSS (в `<style>`),
- HTML-разметку (экраны меню, игры),
- весь JS в одном IIFE (в `<script>`).

Плюс картинки в **той же папке**, что `index.html`:
- `kuznec.png` — открытый кузнец.
- `kuznec-locked.png` — закрытый кузнец.

## Экраны игры

- **Меню** (`menuScreen`): Продолжить / Новая игра.
- **Игра** (`gameScreen`): 5 вкладок.
  - **Кузнец** (`forge`) — открывается после первого престижа. До престижа — `kuznec-locked.png`, плашка 🔒, текст «Откроется после первого престижа». В таббаре — 🔒.
  - **Печь** (`fire`) — выпаривание раствора в слитки, скупщик, продажа.
  - **Копать** (`dig`) — основная вкладка, точки сбора, инвентарь. **Без вертикального скролла.**
  - **Кислота** (`acid`) — растворение лома.
  - **Прокачка** (`upg`) — апгрейды + престиж. Две вкладки: Обычная / Престиж.
- **Оверлей оффлайн-дохода.**
- **Оверлей стоп-игры «Контроль цены».**
- **Две мини-игры:** «Растворение» (кислота) и «Выплавка» (печь).
- **DEV-консоль** — по долгому зажатию (3 сек) на шестерёнку. **Всё ещё в коде**, убрать перед релизом.

## Игровая петля

1. **Копать** — тратится «запас» точки, находит мусор.
2. **Кислота** — растворяет лом. Здесь **один раз** срезается вся потеря цикла (`cycleEff`). Мини-игра перед запуском.
3. **Печь** — выпаривает раствор, получаются слитки. Потерь нет. Мини-игра перед запуском.
4. **Скупщик** — продажа слитков через стоп-игру.
5. **Прокачка** — апгрейды + престиж.
6. **Кузница** (после первого престижа) — крафт амулетов.
7. **Автоматизация** (после покупки в Престиже) — параллельная фабрика.

## Игровые механики (важное)

### Автокопатели (ручные)

- Покупаются за кэш, по одному на локацию: 800 / 2 500 / 6 000 / 15 000 / 35 000 / 80 000 / 180 000 / 260 000 / 400 000 ₽.
- Работают без траты стамины точек.
- Не сбрасываются при престиже.
- Прокачки общие: **«Скорость работяг»** (+10% за уровень, макс 10) и **«Удача работяг»** (шанс двойного дропа, +5% за ур., макс 10 → 50%).
- **Штраф убран полностью** — работяги копают на чистой базовой скорости.

### Оффлайн-доход

- Считается от купленных автокопателей (ручных) + от авто-фабрики.
- **Порог срабатывания — 5 минут.**
- `lastSeenTs` обновляется всегда.
- Лимит часов по умолчанию 1 час, до 10.
- Коэффициент оффлайна — база 0%, +5% за уровень, до 75%.
- Модалка: время, крупная сумма, разбивка «Ручные / Авто», случайная фраза (8 вариантов), кнопка «Забрать».
- Удача работяг в оффлайне учитывается (`1 + autoLuckChance()`).
- Эффективность цикла — через `cycleEffEffective()`.

### Кузница

- Открывается после первого престижа.
- До престижа — `kuznec-locked.png`, 🔒, текст, анимации выключены, заголовок в Прокачке спрятан.
- После престижа — `kuznec.png`, всё включено.

**Анимации (только когда открыта):**
- Дыхание картинки (4.2 сек цикл).
- Дым от сигареты: 7 частиц, точка `50% / 24%`.
- Свечение лампы: `91% / 58%`, цикл 2.4 сек.
- Тёплый пульс снизу.
- Светлячки: 5 точек вокруг лампы (`85–92%` / `46–52%`).
- Замок (когда закрыта) парит вверх-вниз.

### Амулеты (10 штук)

- Один слот одновременно.
- Эффекты: Ночная смена, Второй шанс, Золотая жила, Чистюля, Печной демон, Расширитель, Щедрый скупщик, Мусорщик, Легендарный охотник, Терпеливый.
- Рецепты — чипами `🔌 Микросхемы 3/5`, красные если не хватает.
- **Удаление:** свайп влево → корзина → тап → растворяется, вернёт 40%. Без `confirm`.
- **При престиже:** амулеты остаются, срок в престижах −1.
- Фон карточки амулета — непрозрачный.

**Актуальные эффекты:**
- **«Ночная смена»** — +10% к удаче работяг. Плюсуется к прокачке, кап 99%.
- **«Щедрый скупщик»** — +15% к цене продажи слитков.
- **«Чистюля»** — потери при переработке лома в слитки снижены вдвое (действует на `cycleEff`).
- **«Печной демон»** — кислота и печь работают на 25% быстрее (сокращает длительности обеих стадий).

### Крафт амулетов

- **Один горн** по умолчанию.
- **«Два горна»** — 25 000 ₽, в Прокачке → Кузница.
- Нельзя запустить один и тот же амулет дважды.
- Пока слоты заняты — кнопки «Занят».

### Прокачка кузницы

- «Быстрее куём» — −10% времени за уровень, макс 7.
- «Дешевле рецепты» — −5% ресурсов, макс 10.
- «Дольше живут» — +1 престиж / +25% времени за уровень, макс 5.
- «Два горна» — 25 000 ₽, один раз.

### «Контроль цены» (стоп-игра)

- Доступна с самого начала.
- Кнопка «Продать» → бегунок, зелёная зона, тап → стоп.
- До тапа — диапазон цен (`800 – 4000 ₽/г`).
- Попал в зону → 4000 ₽/г, промазал → от 3900 до 800.
- **«Широкая зона»** — +1% ширины за уровень, макс 5. База 5 000 ₽ × 1.7^lv.

### Престиж

- **Порог:** `100 000 × 1.5^уровень`.
- **Награда:** `10 × 2.5^(уровень-1)`.
- **Максимум 20 уровней** (`MAX_PRESTIGE_LEVEL = 20`).
- **Сбрасывается:** деньги, слитки, лом, раствор, обычные прокачки, локации, склад.
- **Остаётся:** автокопатели, амулеты, очки престижа, апгрейды престижа, купленная автоматизация + все её прокачки + авто-склад/раствор/слитки.

- Копать быстрее 10, Кислота быстрее 20, Печь быстрее 20.
- Второй бак 1, Вторая печь 1.
- Хороший глаз 20, Чуйка 15.
- Репутация 10, Широкая зона 5.
- Оффлайн-коэффициент 15, Оффлайн-лимит 9.
- Скорость работяг 10, Удача работяг 10.
- Кузница: Быстрее куём 7, Дешевле рецепты 10, Дольше живут 5, Два горна 1.
- Престиж: Усиление бонуса 20, Стартовый капитал 20, Скидка на локации 15, Кислота II 10, Печь II 10, Склад II 25.
- Восстановление точек 10.

### Экономика: единая эффективность цикла (вариант А)

**Было (перемножение потерь):** `acidEff × fireEff`. На старте `0.192 × 0.192 = 3.7%`. Максимум без престижа — 25%.

**Стало (одна эффективность):**

    cycleEff = min(
      0.60
      + (lv.acid − 1) × 0.0071
      + (lv.fire − 1) × 0.0071
      + lv.acidII × 0.01
      + lv.fireII × 0.01,
      1.0
    )

- Старт (1/1, без престижа): **60%**.
- Максимум без престижа (15/15): **80%**.
- С «Кислотой II» и «Печью II» на максимуме: **100%**.

**Где применяется:**
- Кислота: `bath.yieldAmt = takenGold × cycleEffEffective()`. Один раз на весь цикл.
- Печь: `f.yieldAmt = taken` (без потерь).
- Оффлайн: `cycleEffEffective()` вместо перемножения.

**Тексты прокачек:**
- «Кислота почище» → «Общая эффективность переработки лома в слитки: X% → Y%».
- «Печь помощнее» → то же самое.
- «Кислота II» и «Печь II» → «доп. эффективность переработки: +N% → +N+1%».

**Почему так:** перемножение двух потерь давало «колесо» — чтобы заработать на апгрейды, нужны деньги, а деньги душит именно двойная потеря. Одна общая эффективность бьёт в корень, а не подкручивает симптомы.

### Темп: актуальные цифры (после последней подкрутки)

- **Кулдаун копки:** `1820 − 117 × lv`, пол 650 мс. (Как было изначально — вернули.)
- **Двор (`yard`):** запас `8`, реген `5200 мс`. (Как было изначально — вернули.)
- **Кислота:** база `6300` мс (было 4200, стало +50%).
- **Печь:** база `5100` мс (было 3400, стало +50%).
- **Шаг прокачек** «Кислота быстрее» и «Печь быстрее» — 160 и 120 соответственно, пол 1000 мс.

Что это дало: старт стал спокойнее, чем в промежуточной версии. Максимумы скоростей кислоты/печи в пол 1000 не упираются (при базе 6300 и шаге 160 на 20 уровнях получится 3100 мс; при 5100 и 120 — 2700 мс).

### «Хороший глаз» — привязка к локации

- При срабатывании заменяет находку **случайным предметом из пула текущей локации** (равновероятно).
- Двор + глаз → дворовые. Институт + глаз → институтские.
- Лестница локаций работает.

### «Удача работяг» (прокачка)

- В Прокачке → Автоматизация, под «Скоростью работяг».
- 10 уровней, +5% за уровень → максимум 50%.
- База 4 000 ₽, ×1.7 за уровень.
- Работает **только** для автокопателей за кэш.
- Шанс проверяется **до** апгрейда предмета.
- Амулет «Ночная смена» плюсует +10% сверху, кап 99%.

### Штраф работяг — убран

- Раньше: `autoCdBase()` умножал интервал на штраф (−50% на старте, до −0% прокачкой «Снижение штрафа»).
- Теперь: штрафа нет, работяги копают на чистой базовой скорости.
- Прокачка «Снижение штрафа» удалена из HTML, списка прокачек, `countBadgeUpg`, `buy`, `renderUpg`.
- Причина: «чужой точки» в игре нет, штраф висел в воздухе.

### Мини-игра «Растворение» (кислота)

- Обязательна перед запуском любого бака кислоты. Со старта.
- Три колбы: 💧 Вода / 🧪 Кислота / ⚗️ Щёлочь.
- Скорость: вода 40, кислота 55, щёлочь 70 %/сек.
- Зона-мера на каждой колбе — своя, случайная (позиция 12–72%, ширина 16–22%).
- Зажал — колба едет вверх, дошла до верха — вниз. Отпустил — стоп.
- Попал — колба зелёная. Промах — красная вспышка, всё заново.
- Все три попал — процесс запускается.
- **Grace 3 сек:** после победы 3 секунды можно запустить второй бак без мини-игры.

### Мини-игра «Выплавка» (печь)

- Обязательна перед запуском печи. Со старта.
- Горизонтальная полоса, оранжевая зона ходит туда-сюда.
- Скорость зоны 35–55 %/сек, стартовая позиция случайна.
- Кнопки «−» и «+». Зажал — бегунок едет. Тап — толчок.
- «Готовность»: в зоне растёт (за 3 сек до 100%), вне зоны падает (за 1 сек до 0%).
- Скрытый счётчик провала: 5 сек вне зоны → провал.
- **Grace 3 сек** — как у кислоты.

### Автоматизация

**Идея:** после покупки «Автоматизации» в Престиже игра получает **параллельную фабрику**. У авто всё своё: склад лома, раствор, слитки, деньги, работяги. Не пересекается с ручным.

**Ручное всегда выгоднее авто.** Авто — про удобство.

**Покупка:** кнопка «Автоматизация» в Престиже, **20 очков**. Одна покупка — включает всё.

**Где живёт:**
- Престиж → кнопка + секция «Автоматизация» с прокачками.
- Кислота → секция «Авто-кислота».
- Печь → секция «Авто-печь».
- Копать → в блоке «Склад» разделитель и «Авто-склад: N/M».
- Скупщик → уведомление «+X ₽» возле денег.

**Прокачки автоматизации (за очки престижа):**
- Авто-работяги (скорость) — 20 уровней
- Авто-склад (вместимость) — 15 уровней (старт 50, +50 за ур., макс 750)
- Авто-кислота (скорость) — 20
- Авто-кислота (чистота) — 15
- Авто-печь (скорость) — 20
- Авто-печь (жар) — 15
- Авто-продажа (скорость) — 10
- Авто-наценка — 10 (40% → 90% от 4000)

**Цена уровней:** 1 очко за 1-й уровень, +1 за каждый следующий (1, 2, 3, 4…).

**Авто-цикл:** работает непрерывно. Есть лом — кислота. Есть раствор — печь. Есть слитки — продаёт по таймеру.

**Уведомление о продаже:** возле плашки денег всплывает «+X ₽» на 1.5 сек, золотого цвета.

**Важно:** у автоматизации **свои** формулы (`autoAcidYield × autoFireYield`), не пересекается с `cycleEff`.

### Визуальная помощь

- Хватает денег — кнопка «горит»:
  - обычные — кислотно-зелёная;
  - престижные — фиолетовая;
  - оффлайновые — голубая.
- Не хватает — серая тихая.

### Бейджи на таббаре

- Круглый значок в углу иконки, кислотно-зелёный, с числом.

  - 🔥 Печь — есть раствор + свободная печь.

  - ⚒️ Кузница — есть свободный горн + хватает материалов.
- Сохраняется в сейв (`badgeSeen`).
