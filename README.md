# ДРАГМЕТ

Идл-игра про бомжа-аффинажника: копаешься в мусоре → собираешь электронику → растворяешь в кислоте → выпариваешь в печи → продаёшь золото скупщику → прокачиваешься → престиж → кузница с амулетами.

## Текущий статус

- **Стадия:** рабочий HTML-прототип, этапы 1–3 плана закрыты, идёт балансировка.
- **Версия:** v0.9 (код сейва `ver: 20`).
- **Формат:** один файл `index.html` + три картинки в той же папке: `kuznec.png` (открытый кузнец), `kuznec-locked.png` (закрытый, размытый силуэт).
- **Где живёт:** GitHub Pages (`txnto-exe.github.io/dragmet`), открывается в Safari на iPhone, добавлен на домашний экран как PWA.
- **Тестируют:** друзья (обычные игроки, не программисты).

## Roadmap

1. ✅ **Этап 1 — фиксы.** Кузница до престижа, свайп амулетов, bloom, DEV-консоль.
2. ✅ **Этап 2 — визуал и удобство.** Оффлайн-модалка, инвентарь, аккордеоны, мини-игра.

4. **Сейчас:** баланс престижа — порог растёт медленнее награды, потолок 50 уровней.
5. **Дальше:** техдолг, пиксельный редизайн, обёртка в `.ipa` / `.apk`, убрать DEV-консоль.

## Технический стек

- **Чистый HTML + CSS + vanilla JS.** Никаких библиотек, фреймворков, npm, сборщиков.
- **Причина:** простота, скорость правок, открывается где угодно, легко превращается в нативное приложение через WebView.
- **Не менять этот принцип** без явной просьбы.

## Структура файла

Один файл `index.html` содержит:
- CSS (в `<style>`),
- HTML-разметку (экраны меню, игры),
- весь JS в одном IIFE (в `<script>`).

Плюс картинки в **той же папке**, что `index.html` (в корне репозитория, не в подпапке):
- `kuznec.png` — открытый кузнец.
- `kuznec-locked.png` — закрытый кузнец (тёмный размытый силуэт, готовится автором).

## Экраны игры

- **Меню** (`menuScreen`): Продолжить / Новая игра.
- **Игра** (`gameScreen`): 5 вкладок.
  - **Кузнец** (`forge`) — открывается после первого престижа. До престижа на иконке — только 🔒 без подписи.
  - **Печь** (`fire`) — выпаривание раствора в слитки, скупщик, продажа.
  - **Копать** (`dig`) — основная вкладка, точки сбора, инвентарь. **Без вертикального скролла** — вся панель подгоняется под высоту экрана.
  - **Кислота** (`acid`) — растворение лома.
  - **Прокачка** (`upg`) — все апгрейды + престиж. Две вкладки: Обычная / Престиж.
- **Оверлей оффлайн-дохода** — при возврате после долгого отсутствия.
- **Оверлей стоп-игры «Контроль цены»** — при продаже слитков.
- **DEV-консоль** — по 5 быстрым тапам на надпись ДРАГМЕТ в шапке.

## Игровая петля

1. **Копать** — на локациях тратится «запас» точки, находит мусор.
2. **Кислота** — растворяет лом, часть золота теряется.
3. **Печь** — выпаривает раствор, получаются слитки.
4. **Скупщик** — продажа слитков через стоп-игру.
5. **Прокачка** — апгрейды + престиж.
6. **Кузница** (после первого престижа) — крафт амулетов из мусора.

## Сохранения

- **Два независимых слота:** `dragmet_save_a_v2` и `dragmet_save_b_v2`.
- Пишем по очереди в тот слот, у которого **меньше** timestamp. Так один слот всегда целый.
- При загрузке берём тот, что свежее.
- **Старые ключи** (`dragmet_save_a`, `dragmet_save_b`, `dragmet_save_v1`, `dragmet_save_v1_backup`) при запуске удаляются.
- **Нельзя:** стирать оба слота не попробовав прочитать, менять структуру сейва без `ver` и миграции.
- **Текущий `ver`: 20.** При загрузке старого сейва без `forgeCrafts` — конвертируется из старого `forgeCraft`.

## Игровые механики (важное)

### Автокопатели (вкладка Прокачка → Автоматизация)

- Покупаются за кэш, по одному на локацию: 800 / 2 500 / 6 000 / 15 000 / 35 000 / 80 000 / 180 000 / 260 000 / 400 000 ₽.
- Работают без траты стамины точек.
- Не сбрасываются при престиже.
- Прокачки общие для всех: «Скорость работяг» (+10% за уровень, 5 000 ₽ × 1.6^lv) и «Снижение штрафа» (−5% за уровень, 3 000 ₽ × 1.8^lv, максимум 10 уровней).
- Автокопатели замедлены в 3 раза (`AUTO_SLOW_FACTOR = 3`). Оффлайн-доход считается от этой же замедленной скорости.

### Оффлайн-доход

- Считается от купленных автокопателей.
- **Порог срабатывания — 5 минут.** Меньше — плашка не вылезает.
- `lastSeenTs` обновляется всегда, даже если доход 0.
- Лимит часов по умолчанию 1 час, прокачивается до 10.
- Коэффициент оффлайна — база 0%, +5% за уровень, максимум 75%.
- **Модалка упрощена:** время отсутствия, крупная сумма `+N ₽`, случайная фраза (8 вариантов, только про работяг — про кузнеца убрали), кнопка «Забрать». Никаких «Скорость/Лимит/Засчитано».

### Кузница

- **Открывается после первого престижа.**
- **До престижа:** зайти **можно**. Внутри `kuznec-locked.png` нормальной яркости, поверх — блюр-плашка с большим 🔒 и надписью «ЗАКРЫТО». Все анимации выключены. Заголовок «Кузница» скрыт. На иконке в таббаре — только 🔒 без подписи.
- **После престижа:** `kuznec.png`, все анимации включены, заголовок и аккордеон «Кузница» в Прокачке видны, в таббаре ⚒️ + «Кузнец».

**Анимации кузнеца (только когда открыта):**
- Дыхание всей картинки (лёгкое покачивание, цикл 4.2 сек).
- Дым от сигареты: 7 частиц, левая точка `50% / 24%`.
- Свечение лампы: жёлтое пятно `91% / 58%`, мерцает циклом 2.4 сек.
- Общий тёплый пульс снизу.
- Светлячки: 5 тёплых точек вокруг лампы (`85–92%` слева, `46–52%` сверху), летают по кругу.

### Амулеты (10 штук)

- Один слот, одновременно носишь только один.
- Эффекты:
  - **Ночная смена** — автокопатели без штрафа вне активной точки.
  - **Второй шанс** — переброс при промахе в стоп-игре.
  - **Золотая жила** — +15% шанс ценного дропа.
  - **Чистюля** — потери в кислоте ÷2.
  - **Печной демон** — потери в печи ÷2.
  - **Расширитель** — +8 мест склада.
  - **Щедрый скупщик** — продажа без стоп-игры даёт +15%.
  - **Мусорщик** — мусор ×3 в дропе.
  - **Легендарный охотник** — +5% шанс легендарки.
  - **Терпеливый** — бегунок в стоп-игре ×0.5.
- У каждого свой цвет, свой рецепт, свой срок годности.
- **Срок годности:** в престижах или в реальных часах. Сгорает автоматически.
- **Рецепты** отображаются чипами: `🔌 Микросхемы 3/5` — красный если не хватает.
- **Удаление (свайп влево):** свайпнул → открылась красная корзина 🗑️ → тапнул → амулет растворился, вернулось 40% материалов, всплыл тост. Без браузерного `confirm`. Раскрытое состояние живёт в `window._revealedAmulet` и восстанавливается при перерисовке.
- **При престиже амулеты остаются**, но срок в престижах уменьшается на 1.

### Крафт амулетов

- **Один горн** по умолчанию.
- **«Два горна»** — покупка один раз, 25 000 ₽ (в Прокачке → Кузница). Позволяет запустить два амулета параллельно.
- Пока слоты заняты — у остальных амулетов кнопка «Занят».
- Блоки крафта сверху кузницы: 1 или 2 блока с баром и таймером. Название — «Куётся» (один горн) или «Горн #1 / Горн #2» (два горна).

### Прокачка кузницы (в разделе Прокачка → Кузница)

- **Быстрее куём** — −10% времени ковки за уровень, максимум 7 уровней (−70%).
- **Дешевле рецепты** — −5% ресурсов, максимум 10 уровней (−50%).
- **Дольше живут** — +1 престиж / +25% времени за уровень, максимум 5 уровней.
- **Два горна** — покупка один раз, 25 000 ₽.

### «Контроль цены» (стоп-игра)

- **Доступна с самого начала.** Покупать не надо — убрали из прокачки.
- Кнопка «Продать» → стоп-игра: бегунок, зелёная зона, тап → стоп.
- **До тапа** в поле результата — диапазон цен (мелким серым): `800 – 4000 ₽/г`.
- **После тапа** — выпавшее число (крупно).
- Попал в зону → 4000 ₽/г, промазал → от 3900 до 800.
- Бонусы престижа и репутации применяются сверху.

**«Широкая зона»** (в Прокачке → Доход) — +1% ширины зелёной зоны за уровень, максимум 5 уровней. База 5 000 ₽ × 1.7^lv.

### Престиж

- **Порог сейчас:** фиксирован 100 000 ₽ (план — см. ниже).
- **Награда:** `10 × 2.5^(уровень-1)` — то есть 10, 25, 62, 156, 390, ... без потолка.
- **Бонус к продаже:** `(5 + bonusBoost) × уровень`.
- **Порог сейчас:** фиксирован 100 000 ₽ (план — см. ниже).
- **Что сбрасывается:** деньги, слитки, лом, раствор, все прокачки обычной вкладки, локации, склад. **Остаются:** автокопатели, амулеты, очки престижа, апгрейды престижа.

### Звук

- Единый уровень громкости `SND_VOL × VOL_MUL = 0.07 × 14`.
- Тон кислоты растёт от прогресса: 600 → 1800 Гц.
- Печь — частое потрескивание дерева, 800–1800 Гц.
- 10 вариантов надписей на кнопке копания, случайная при каждом старте.

### Тост о находке

- **Внутри вкладки «Копать»** — плавающий, позиционируется **по строке навигации локаций** (там где «1 / 3» между стрелками). Не перекрывает кнопку «Порыться» и не загораживает интерфейс.
- **В остальных вкладках** (кузница, престиж) — по центру панели, как раньше.
- Цвет по тиру предмета:
  - мусор — серо-зелёный
  - обычное — светлый
  - ценное — голубой
  - редкое — фиолетовый
  - легендарка — золотой со свечением

### Управление касаниями

- **Кнопки «Копать» и «Продать»** — моментально (задержка 30 мс). Держишь → турбо-палец. Сдвинул палец >12px → не копает и не скроллит.
- **Всё остальное** (карточки, апгрейды, вкладки, аккордеоны, старт кислоты/печи) — срабатывает **при отпускании**, если палец не сдвинулся. Сдвинул → обычный скролл.

### Скроллбары

Скрыты везде — вертикальные и горизонтальные, включая ленту локаций.

### Вкладка «Копать» — особенности

- **Без вертикального скролла.** Экран делится на фиксированные зоны: шапка, лента точек, строка навигации, кнопка «Порыться», полоска склада, инвентарь. Всё влезает в `100dvh` на любом телефоне.
- **Точки сбора:** по 3 карточки на страницу, страниц — 3 (всего 9 локаций). Переключение — стрелками ← → под лентой. Плавный слайд через `translateX` (0.32 сек).
- **Инвентарь:** всегда открыт, 16 предметов, сетка **4 колонки × 4 ряда** — ровный квадрат. Кнопка «Показать все виды / Свернуть» убрана.

## ПЛАН РАБОТ (актуальный)

### ЭТАП 4 — баланс престижа

**Проблема:** порог сейчас фиксирован 100 000 ₽, а награда растёт как `2.5^N`. Через 3-4 престижа цикл схлопывается в 60 секунд.

**Решение:** вариант A — порог растёт медленнее награды.

- **Формула порога:** `100 000 × 1.5^уровень`.
  - Престиж 0 → 1: 150 000 ₽
  - 1 → 2: 225 000 ₽
  - 2 → 3: 337 500 ₽
  - ...
  - 49 → 50: ~63,7 трлн ₽
- **Награда:** без изменений — `10 × 2.5^(уровень-1)`.
- **Максимум:** 50 уровней. **После 50 кнопка престижа блокируется навсегда** — это финал.
- **Очки:** пока не трогаем. В будущем — добавить дорогие апгрейды и сделать конечными все прокачки вообще (не только престиж).

### ЭТАП 5 — техдолг

- `flashInvItem` по русскому имени → по ключу.

- Повторы в коде — вынести.

### ЭТАП 6 — пиксельный редизайн

Одним заходом: единый пиксельный шрифт, пиксельные иконки вместо emoji, жёсткие края, пиксельные элементы интерфейса.

## Легенда терминов

- **Сейв** — сохранение прогресса.
- **Слот** — один из двух независимых файлов сохранения.
- **Престиж** — сброс прогресса за постоянные бонусы.
- **Автокопатель** — «работяга» на локацию, копает в фоне за кэш.
- **Стамина (запас точки)** — сколько предметов ещё можно найти. Пополняется со временем.
- **dt** — «delta time», время между кадрами. Всё, что зависит от времени, умножается на `dt`.
- **PWA** — веб-приложение, добавленное на домашний экран.
- **WebView** — встроенный браузер внутри нативного приложения.
- **Стоп-игра** — мини-игра с бегунком и зелёной зоной (внутриигровое имя — «Контроль цены»).
- **Bloom** — свечение от амулета по краям экрана.
- **Дев-консоль** — скрытая панель для тестов, откроется по 5 тапам на логотип.
- **dvh** — динамический viewport height, учитывает адресную строку Safari.
