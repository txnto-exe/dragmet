# ДРАГМЕТ — чужие материалы

Всё ниже можно использовать в коммерческой игре (Steam).

| Что | Откуда | Лицензия |
|---|---|---|
| 3D-модели предметов подвала, фото-текстуры стен, пола, металла | [Poly Haven](https://polyhaven.com) | CC0 |
| Базовые 3D-персонажи, причёски | [Quaternius — Universal Base Characters](https://quaternius.com/packs/universalbasecharacters.html) | CC0 |
| Анимации персонажей | [Quaternius — Universal Animation Library 1 и 2](https://quaternius.com/packs/universalanimationlibrary.html) | CC0 |
| Шрифт Pixelify Sans | [Google Fonts](https://fonts.google.com/specimen/Pixelify+Sans) | SIL OFL 1.1 (файл `assets/fonts/OFL.txt`) |

Одежда персонажей нарисована скриптом `tools/paint_clothes.py`, звуки синтезированы `tools/gen_sfx.py`.
